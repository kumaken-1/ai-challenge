**入口: https://kumaken-1.github.io/ai-challenge/**

## 設計について

- **一度試して離れた人にも入口を置いています。**「使ったことがない人」だけに呼びかけると、前に試して期待はずれだった人が自分の話だと思えません。
- **読む順を誘導しません。**「まずここから」は置かず、各巻に「誰向けか」を書いて、読んだ人が自分で選べるようにしています。
- **各巻は統合していません。**それぞれ独立したページで、これまでに配ったURLはすべて生き続けます。
- **記録は巻ごとに別々です。**「やってみた」の印は使っている端末に残りますが、巻をまたいで混ざりません。

## 更新するとき

`index.html` の1ファイルだけです。ビルドはありません。巻が増えたときは、カードを1つ足して、`README.md` の表にも1行足してください。
